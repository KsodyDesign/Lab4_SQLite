## Описание проекта
Приложение разработано в рамках лабораторной работы №4 по курсу мобильной разработки для ОС Android.

Цель работы — освоение взаимодействия со штатной реляционной СУБД SQLite напрямую, без высокоуровневых ORM/абстракций (таких как Room).

### Реализованный функционал:
1. **Класс `NotesDbHelper` (наследник `SQLiteOpenHelper`)**:
   - Создание таблицы `notes` в `onCreate()` с полями `id` (INTEGER PRIMARY KEY AUTOINCREMENT), `title` (TEXT NOT NULL), `content` (TEXT), `timestamp` (INTEGER).
   - Управление версионированием и миграцией в `onUpgrade()`.
   - Полная реализация CRUD-операций:
     - `insertNote(title, content)` — вставка новой записи через `ContentValues` и `db.insert()`.
     - `getAllNotes()` — выполнение SQL-запроса через `db.query()`, проход по объекту `Cursor` с безопасным закрытием через `cursor.use { ... }`.
     - `updateNote(id, title, content)` — обновление заметки по первичному ключу.
     - `deleteNote(id)` — удаление заметки по идентификатору.

2. **Асинхронность и многопоточность**:
   - Все обращения к SQLite вынесены в фоновый пул потоков с помощью Kotlin Coroutines (`Dispatchers.IO`), исключая блокировку главного потока UI.
   - Обновление интерфейса и адаптера выполняется строго в основном потоке (`Dispatchers.Main`).

3. **Пользовательский интерфейс**:
   - Поля ввода для заголовка и текста заметки с валидацией обязательного заполнения.
   - Кнопки операций: «Добавить», «Обновить», «Удалить», «Сброс».
   - Список заметок на базе `RecyclerView` с отображением названия, превью текста и форматированной даты создания/изменения.
   - Выбор заметки по клику из списка для последующего редактирования или удаления.

## Сборка и запуск
- Минимальная версия Android SDK: API 24 (Android 7.0)
- Целевая версия Android SDK: API 37
- Язык разработки: Kotlin
- Готовый установочный файл приложения: `app-debug.apk` в корне репозитория.
